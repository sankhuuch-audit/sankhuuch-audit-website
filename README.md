# “Санхүүч-Аудит” ХХК — вэбсайт

Компанийн мэргэжлийн вэбсайт: танилцуулга, үйлчилгээ, санхүү, татварын зөвлөгөө, YouTube видео сан, хэрэгцээт мэдээлэл, холбоо барих.

- **Технологи:** [Eleventy](https://www.11ty.dev/) статик сайт. Сервер, мэдээллийн сан шаардлагагүй.
- **Хостинг:** GitHub Pages (үнэгүй, HTTPS үнэгүй).
- **Агуулга засах:** [Pages CMS](https://app.pagescms.org) — хөтөч дээр маягт бөглөж нийтлэл, видео, материал нэмнэ. Код өөрчлөх шаардлагагүй.

Байршуулах, домэйн холбох дэлгэрэнгүй алхмыг тусад нь өгсөн гарын авлагаас харна уу.

## Агуулга хаана байдаг вэ

| Хавтас / файл | Юу байдаг |
|---|---|
| `src/content/articles/` | Зөвлөгөө, нийтлэл (`.md` файл бүр нэг нийтлэл) |
| `src/content/videos/` | YouTube бичлэгүүд |
| `src/content/materials/` | «Мэдээлэл» хуудасны татах файлууд (календарь, гарын авлага) |
| `src/content/services/` | Үйлчилгээнүүд |
| `src/_data/site.json` | Хаяг, утас, имэйл, YouTube суваг, Facebook |
| `src/_data/company.json` | Компанийн тоон үзүүлэлт, түүх, эрхэм зорилго, зарчим, баг, гэрчилгээ |
| `src/_data/categories.json` | Нийтлэлийн 5 ангилал |
| `src/assets/uploads/` | Pages CMS-ээр оруулсан зураг, файл |
| `.pages.yml` | Pages CMS-ийн маягтын тохиргоо |
| `.github/workflows/deploy.yml` | Өөрчлөлт бүрийн дараа сайтыг автоматаар байршуулах тохиргоо |

## Ажиллах зарчим

1. Pages CMS дээр нийтлэл нэмж «Save» дарна.
2. GitHub дээр өөрчлөлт хадгалагдана.
3. GitHub Actions 1–2 минутад сайтыг дахин бүтээж байршуулна.

`draft: true` (Ноорог) гэж тэмдэглэсэн нийтлэл, видео вэбсайт дээр гарахгүй. `src/content/articles/2026-01-01-zhishee-niitlel.md` бол нийтлэлийн загвар харуулах ноорог жишээ. Шаардлагагүй бол устгаж болно.

## Жил бүр шинэчлэх зүйлс

Pages CMS → «Компанийн мэдээлэл» хэсэгт:

- «18 жил», «18 дахь жилдээ» гэсэн тоонууд
- Харилцагчдын тоо (жилээр), жилийн дундаж
- Түүхэн замналд шинэ үйл явдал

## Компьютер дээрээ туршиж үзэх (заавал биш)

[Node.js](https://nodejs.org) 20 ба түүнээс дээш хувилбар суулгасан байх шаардлагатай.

```bash
npm install
npm start          # http://localhost:8080 хаягаар нээгдэнэ
npm run preview    # ноорог нийтлэлүүдийг хамт харуулна
npm run build      # бэлэн файлуудыг _site хавтсанд гаргана
```
